# 💬 Template Chat Pribadi (Japri 1-on-1 ke Owner Server)

Template ini dirancang khusus untuk chat langsung ke owner / admin server Minecraft. 
Gaya bahasa dibuat **hangat, personal, sesama penikmat Minecraft**, dan **tidak terkesan seperti sales/bot**.

> 💡 **Petunjuk Penting Sebelum Kirim:**
> Ganti `[Nama Owner]` dengan nama panggilan mereka, dan `[Nama Server]` dengan nama server aslinya. Jangan biarkan tanda kurung siku terbawa saat mengirim chat!

## 💡 Tips Penting Saat Kirim di WhatsApp

1. **Tunggu Preview Gambar Muncul:**
   Setelah paste teks di atas ke chat WhatsApp si owner, **tunggu 1–2 detik** sampai kotak pratinjau bergambar banner EterVerse muncul di atas pesan sebelum menekan **Kirim**.
2. **Kesan Tulus:**
   Jangan langsung spam banyak orang sekaligus dalam waktu bersamaan. Kirim santai satu per satu dan ajak ngobrol jika mereka membalas.
